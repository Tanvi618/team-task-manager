Team Task Manager

A full-stack web application designed to help teams manage projects and tasks in a simple and structured way. It focuses on improving collaboration by keeping everything organized in one place.

About the Project

This project allows users to create projects, assign tasks to team members, and track their progress easily. It also includes role-based access so that different users have different permissions based on their role in the system.

The main idea was to understand how real-world task management systems work and how frontend, backend, and database interact together.

Features
User Authentication (Signup / Login using JWT)
Role-based Access Control (Admin & Member)
Create and manage projects
Add, assign, and update tasks
Task status tracking (Pending / In Progress / Completed)
Dashboard to view overall task progress
Basic validation on forms and API requests

Tech Stack

Frontend:

React (Vite)
Axios
React Router

Backend:

Node.js
Express.js
MongoDB
